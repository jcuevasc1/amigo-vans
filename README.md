# Amigo Vans — sitio web

Sitio web de Amigo Vans, compañía de conversión de vans y sprinters a casas rodantes (RV).

## Estructura

```
amigo-vans/
├── index.html          # Página principal
├── css/
│   └── styles.css      # Estilos del sitio
├── js/
│   └── main.js         # Interacciones (menú móvil, formulario)
├── fotosVans/           # Fotos usadas en la galería
├── GUIA_PASO_A_PASO.md  # Guía completa: local → GitHub → Hostinger
└── README.md
```

## Cómo ver el sitio localmente

No necesita servidor ni instalación. Solo abre `index.html` en tu navegador
(doble clic, o clic derecho → "Abrir con" → tu navegador).
